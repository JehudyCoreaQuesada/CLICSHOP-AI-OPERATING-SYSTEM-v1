También existen copias del libro y logo en esta carpeta, conservadas tal como
fueron encontradas. Se comprobó que coinciden mediante SHA-256 con las de
`imagen de marca/`; esa carpeta es la referencia canónica para futuras revisiones.

La identidad y el eslogan son datos de marca confirmados. Las medidas, estructura
de la tienda y Poppins + Open Sans son propuestas de diseño, no nuevas decisiones
oficiales. Ninguna captura de otra tienda es un recurso publicitario de Clicshop.
