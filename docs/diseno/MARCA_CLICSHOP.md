# Referencia de marca de Clicshop

Fuente principal: [libro de marca de Clicshop](../../imagen%20de%20marca/LIBRO%20DE%20MARCA%20CLICSHOP%20COSTA%20RICA.jpg),
recibida el 2026-09-23. Esta referencia prevalece sobre la extracción automática
de Pomelli de la página de acceso previo al lanzamiento.

## Identidad

Archivo disponible: [logotipo oficial](../../imagen%20de%20marca/Logo_Clic_Shop%20Oficial%20Version.png).

El logotipo combina una C blanca dentro de un círculo naranja con el nombre
`Clicshopcr` en azul. Mantener las proporciones del archivo original. La lámina
incluye ejemplos de uso correcto e incorrecto, pero no especifica medidas de
área de protección ni tamaño mínimo: no inventarlos como reglas oficiales.

## Paleta

| Función indicada en el libro | Color |
|---|---|
| Naranja principal de marca y llamadas a la acción | `#EE601E` |
| Azul principal de marca | `#1A47B1` |
| Estado hover de llamadas a la acción | `#FF8A3D` |
| Azul secundario | `#4F77B5` |
| Líneas y bordes secundarios | `#D1D8E0` |
| Texto de párrafos | `#333333` |
| Fondo de interfaz | `#F8F9FB` |
| Blanco / fondo puro | `#FFFFFF` |

Los colores `#1e2d7d`, `#00badb`, `#f3f5f6` y `#677279` detectados por Pomelli
no sustituyen esta paleta. Comprobar legibilidad y contraste en las combinaciones
reales antes de implementar botones y texto.

## Tipografía: alternativas, no selección definitiva

- Títulos H1–H3: Roboto o Poppins; sans serif en negrita.
- Cuerpo: Open Sans o Lato.
- La lámina recomienda Google Fonts. No especifica una combinación única ni una
  escala de tamaños, pesos exactos, alturas de línea o espaciados.
- Poppins ya figura en Pomelli y es compatible con una de las opciones del libro;
  eso no decide por sí solo la tipografía de cuerpo.

## Misión

Facilitar el acceso a productos de calidad con un servicio eficiente y transparente.

## Valores

- Confianza.
- Claridad.
- Eficiencia.
- Accesibilidad.

## Voz

- Amigable y directa.
- Transparente.
- Confiable.

## Aplicación propuesta al diseño

Usar fondos claros, el azul para identidad y jerarquía visual, y el naranja para
las acciones de compra. Organizar el contenido con títulos legibles, fotografías
consistentes y mensajes claros. Esta orientación aplica los colores y la voz del
libro; no añade afirmaciones comerciales ni acuerdos con proveedores.
