# RELEVO — traspaso de contexto entre IA

Claude lo entrega al cerrar cada sesión de trabajo. ChatGPT lo emite cuando termina de definir o revisar algo.
Si una IA cambia, se lleva este bloque y nada más.

```
=== RELEVO ===
De: Claude | ChatGPT → Para: ChatGPT | Claude
Proyecto: P-XXX · Nombre · Fase
Fecha: AAAA-MM-DD
Repositorio: github.com/JehudyCoreaQuesada/continuidad-proyectos-ia (proyectos/P-XXX-…/ESTADO.md)

Qué cambió en esta sesión:
- … (Propuesto / Implementado / Verificado + evidencia)

Decisiones nuevas: D-00X — resumen
Pendientes abiertos: …
Bloqueos: …
Qué se pide al receptor: revisión crítica de X / definir Y / priorizar Z
Siguiente acción: quién — qué
=== FIN RELEVO ===
```
